## 9. Building

Anything solid the player carries can be placed as a tile. Crafted structures add function. Building exists to solve real problems the simulation creates: collapsing ceilings, floods, long hauls, darkness, and colony troubles.

### Placeable things

| Structure       | Purpose                           | Notes                                                                    |
| --------------- | --------------------------------- | ------------------------------------------------------------------------ |
| Material blocks | Walls, floors, plugs for leaks    | Any solid material; inherits its properties (an obsidian wall insulates) |
| Support beam    | Extends ceiling span              | Span bonus depends on the beam's material                                |
| Ladder, rope    | Vertical movement                 | Ropes can be thrown down a shaft                                         |
| Platform        | One-way floor                     | Drop through by swiping down                                             |
| Door            | Blocks fluids and gas when closed | Creatures can open doors to their own homes                              |
| Torch, lantern  | Light                             | Torches burn out; lanterns need refueling slowly                         |
| Pipe, pump      | Move fluids                       | Drains floods, feeds water to forges, fills moats                        |
| Rail, cart      | Haul heavy loads                  | Carts carry far more than a pack                                         |
| Winch elevator  | Fast vertical travel              | The first big quality-of-life build                                      |
| Storage chest   | Holds items                       | Crafting reads from chests nearby                                        |
| Bed             | Rest point                        | Marks home; see rescue rules in section 12                               |
| Marker          | Map pin and sign                  | Shows up in the journal map                                              |

### Camp

The player's first camp sits on the surface. Players can build more camps anywhere. Any place with a bed, a chest and a light counts as a camp, and camps act as quick-travel targets along rails and elevators the player built. There is no teleporting; travel speed comes from infrastructure.

### Building for colonies

Colonies ask for help by showing an icon of what they need (a wall, a pump, light, a bridge). The player builds it in the world, and colony members actually use it. A pump the player built keeps their homes dry for good, and they remember who built it.
